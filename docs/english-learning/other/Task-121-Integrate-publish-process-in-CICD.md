### 值得模仿的句式
1. **“Integrate X in Y.”** — 将 X 集成到 Y 中。 — Integrate the test runner in the CI pipeline.
2. **“Automate the X process.”** — 将 X 流程自动化。 — Automate the build process for every pull request.
3. **“Set up X for Y.”** — 为 Y 配置/搭建 X。 — Set up CI/CD for the mobile app.
4. **“The X pipeline deploys Y.”** — X 流水线负责部署 Y。 — The CI/CD pipeline deploys the latest release automatically.
