# Becoming 项目 Issue 英语学习材料

本目录按 GitHub issue 的 Epic → Feature → Task 父子关系组织，每个 issue 对应一个 markdown 文件，包含：

1. **Original English** — issue 原文（一字不差保留）。
2. **中文翻译** — 自然流畅的中文翻译。
3. **英语学习重点** — 高频技术动词、固定搭配、值得模仿的句式、领域词汇。
4. **小练习** — 3–5 道基于该 issue 表达的填空题，答案折叠在 `<details>` 中。

## 使用建议

- 按 Epic 主题系统学习，比如先读 `Epic-1` 再读其下的 Feature 和 Task。
- 重点积累 **Outcome / Scope / Acceptance criteria / Out of scope** 等常见章节里的表达。
- 把 **固定搭配** 和 **值得模仿的句式** 抄到自己的 issue/PR 写作模板里。
