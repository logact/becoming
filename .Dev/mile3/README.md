# Mile 3 — Roadmap Milestones

This folder contains the review and implementation artifacts for the Project Roadmap feature.

- [Interactive UI prototype](./roadmap-milestones-prototype.html)
- [Implementation plan](./roadmap-milestones-implementation-plan.md)

The settled model is:

```text
Project pursuit -> Roadmap Milestones -> assigned descendant Goals
```

A Milestone is a checkpoint that groups one or more Goals beneath the Project's pursued Goal. It is reached automatically when every assigned Goal is complete.
